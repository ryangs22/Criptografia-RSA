NEXKEY

Criptografe e Descriptografe mensagens usando o algoritmo RSA (baseado em números primos grandes). Este algoritmo é amplamente utilizado para proteger dados sensíveis, garantindo a confidencialidade e a integridade das informações.

- NÃO é permitido letras com acento (como à, é, í).
- Apenas os caracteres de 32-126 da tabela ASCII são aceitos.
- Recomenda-se utilizar números primos grandes (p e q) para aumentar a segurança da chave pública.
